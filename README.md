## 🌟 Features

- **🌐 Interactive Static Application**: Built with HTML5, Tailwind CSS, and pure JavaScript. Deployed directly on GitHub Pages.
- **⚡ Client-Side State Management (`WayfareState`)**: Persistent local storage for user authentication, holiday packages, bookings, customer enquiries, and reviews moderation.
- **🗺️ Destination & Package Explorer**: Filter by destination, price range, regions (Europe, Asia, Middle East), and user ratings.
- **💳 Integrated Checkout & Payments**: Mock payment gateway supporting Credit Card, UPI / QR Code, and Net Banking with automated receipt generation and printable PDF format.
- **🛠️ Admin Panel & Moderation**: Dedicated admin dashboard (`admin.html`) to manage bookings, add new packages, approve customer reviews, and respond to enquiries.
- **🤖 Live Travel Assistant Chatbot**: Built-in 24/7 AI chatbot assistant for instant package recommendations and trip planning assistance.
